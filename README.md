# Calculadora de Áreas y Perímetros en C

## Descripción

Este proyecto consiste en una calculadora desarrollada en lenguaje C que permite obtener el área y el perímetro de diferentes figuras geométricas a partir de las medidas ingresadas por el usuario.

El programa funciona mediante un menú interactivo en consola y utiliza fórmulas matemáticas para realizar los cálculos correspondientes.

## Características

* Cálculo del área y perímetro de un cuadrado.
* Cálculo del área y perímetro de un rectángulo.
* Cálculo del área y perímetro de un triángulo.
* Cálculo del área y circunferencia de un círculo.
* Menú interactivo para seleccionar figuras.
* Validación de medidas positivas.
* Comprobación de las condiciones para formar un triángulo válido.
* Presentación de resultados con dos decimales.

## Tecnologías utilizadas

* Lenguaje de programación: C.
* Compilador: GCC.
* Entorno de ejecución: Terminal o consola.

## Requisitos

* Tener instalado un compilador de C, como GCC.
* Contar con una terminal o consola para ejecutar el programa.

## Compilación y ejecución

### 1. Compilar el programa

```bash
gcc CalculadoraAreasPerimetros.c -o CalculadoraAreasPerimetros
```

### 2. Ejecutar en Windows

```bash
CalculadoraAreasPerimetros.exe
```

### 3. Ejecutar en Linux

```bash
./CalculadoraAreasPerimetros
```

## Fórmulas utilizadas

### Cuadrado

* Área = lado × lado.
* Perímetro = 4 × lado.

### Rectángulo

* Área = largo × ancho.
* Perímetro = 2 × (largo + ancho).

### Triángulo

* Área = (base × altura) / 2.
* Perímetro = lado 1 + lado 2 + lado 3.

### Círculo

* Área = π × radio².
* Circunferencia = 2 × π × radio.
